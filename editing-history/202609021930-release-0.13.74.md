# Release 0.13.74

2026-09-02 19:30 CST

## English

- Prepared Calcit and `@calcit/procs` 0.13.74 from the latest `main`, keeping the Rust crate and npm runtime package on one version.
- Included the strict nil-boundary work, typed `filter-map-kv` decisions, bundled-core Dynamic debt gate, homogeneous public equality, typed receiver-method lowering, stable nominal impl callables, typed literal-path lowering, and strict Map key/value nil-sentinel rejection completed since 0.13.73.
- Kept generated `&scope:name` symbols as compiler/backend ABI while application code continues to use lowercase receiver-style `.name` calls.
- Recorded the release preparation and required full Rust, native, JavaScript, IR, WASM, documentation, and quality-gate verification before tagging.

## 中文

- 基于最新 `main` 准备 Calcit 与 `@calcit/procs` 0.13.74，保持 Rust crate 和 npm runtime package 使用相同版本号。
- 收录 0.13.73 之后完成的严格 nil 边界、类型化 `filter-map-kv` decision、内置 core Dynamic 债务门禁、同类型公共相等判断、类型化 receiver method lowering、稳定 nominal impl callable、类型化字面量路径 lowering，以及严格 Map key/value nil sentinel 拒绝。
- 生成的 `&scope:name` 继续只作为 compiler/backend ABI；应用代码仍使用小写 receiver-style `.name` 调用。
- 记录本次发布准备；打 tag 前必须完成 Rust、native、JavaScript、IR、WASM、文档和质量门的全量验证。
