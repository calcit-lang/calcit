# Generated WASI HTTP recipe / 生成式 WASI HTTP 配方

## 中文

- 将 `examples/wasi-http-client` 从手写 Rust ABI host 收敛到 calcit-bindgen 生成的 runnable Component 与默认拒绝 Wasmtime host。
- 用一份仓库内 Cirru EDN capability 模板固定 Component 路径、严格类型参数、origin、响应上限和 preopen；本机配置留在生成目录之外。
- 文档统一 Calcit 0.18.0 + calcit-bindgen 0.1.6 的 generate/check/run 流程，并说明 Cargo 运行产物不影响重复 check 或安全再生成。
- 以定义上的五个 `:tests` 和真实本机 HTTP success、capability-denied、response-too-large 路径验证业务与宿主语义。

## English

- Replace the hand-written Rust ABI host in `examples/wasi-http-client` with the runnable Component and default-deny Wasmtime host generated by calcit-bindgen.
- Pin the Component path, strict typed arguments, origins, response limit, and preopens in one repository Cirru EDN capability template while keeping local configuration outside generated output.
- Align documentation on the Calcit 0.18.0 + calcit-bindgen 0.1.6 generate/check/run lifecycle, including repeatable checks and safe regeneration after Cargo runtime artifacts.
- Verify business and host semantics through five definition `:tests` plus real local HTTP success, capability-denied, and response-too-large paths.
