# Release 0.13.73 / 发布 0.13.73

- Adds the opt-in `--strict-types` zero-debt preflight for Dynamic, nil,
  unsafe coercions, and untyped JavaScript FFI boundaries.
- Diagnoses raw Struct indexes without matching nominal layout evidence while
  preserving verified compiler/runtime IR.
- Rejects accidental `decode-map-as` calls on already nominal Struct values at
  preprocessing time.
- Includes review fixes for eval/exec preflight reuse, actionable diagnostics,
  and runtime Struct primitive fixtures.
