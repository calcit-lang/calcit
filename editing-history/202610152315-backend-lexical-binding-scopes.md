# JS 名字与 WASM let 词法作用域

## 依据

消费者的真实 JS 回放发现 `new` 局部变量被原样生成为 ES Module 保留字（#2092）。
将正常的局部读取、同名内层绑定、参数、解构和 match 断言放进 `calcit.core/let`
的 `:tests` 后，又发现 WASM 内层 let 退出后仍使用内层值（#2098）。
两者都是 backend 没有保持已有表层语义，不需要调用方改名或新增类型规则。

## 决定

- JS 沿用现有保留字转义机制，补齐 `new` 的编码和反向可读名字；不改变源语言的名字规则。
- WASM 的单绑定和多绑定 let 复用一个作用域函数，保存当前名字的 value/type/closure
  lookup metadata，在原外层环境解析和求值 RHS，再引入绑定执行 body。
- body 成功或返回生成错误后都恢复旧 metadata；已经发出的 local slots 保留，
  不回退 local index 或删除仍被指令使用的存储。只保存被遮蔽的名字，不复制整个环境。
- 闭包仍在创建位置捕获已有词法绑定；没有新建动态分派、unsafe 或业务 fallback。

## 验证

用户语义在两项 Calcit 附带测试中断言，交给原共享运行器回放；不维护第二套后端断言，
不删除旧测试、不改预期、不增加排除项。JS 字符编码的原 Rust 单测补齐往返断言。
完整结果与精确 SHA 留在关联 PR；本记录不把进行中的验证写成已完成发布。
