# WASI 0.3 `get-env` 命令 lowering

公开的 Calcit `get-env` 继续返回 `Option<String>`，Preview 1 路径不变。WASI 0.3 command Component 导入 `wasi:cli/environment@0.3.0#get-environment`。编译器内部处理 Canonical ABI 的 `list<tuple<string,string>>` 布局，按 UTF-8 字节精确查找名称，只把命中的值复制为 Calcit 字符串。缺失值在底层 primitive 边界为 nil，再由已有 core wrapper 转成 `%none`；空字符串值仍为 `%some |`。

选中的值复制完成后，回收宿主返回的 Canonical ABI 列表、其中字符串和结果区。此改动不增加命令行入口、公开类型、WIT 生成器或隐式环境权限；宿主环境访问仍受 Wasmtime 显式授权限制。

验证包括定义上的 Calcit `:tests`（缺失值契约）以及 Wasmtime 49.0.0 实际命令测试（缺失、空、普通和 UTF-8 值）。两个 `Option` 值直接做相等比较暴露了独立的 WASM 结构相等缺陷，已由 #1293 追踪；本次集成测试使用 `some?` 与 `unwrap-or` 隔离环境能力本身。
