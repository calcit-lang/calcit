# Release 0.13.77

2026-09-04 23:49 CST

## English

- Stabilize strict diagnostics for implicit Optional, bare containers,
  unbound type slots, whole-Dynamic contracts, erased generic relations,
  dynamic method dispatch, raw primitives, and JS FFI boundaries.
- Preserve and specialize typed collection, Ref, nominal, and callable
  contracts across native, JavaScript, IR, and WebAssembly backends.
- Publish audited bundled-core Dynamic classification with Linux PR/release
  drift gates and cross-module isolation for process-wide Rust test state.
- Refine Interface IR v2 diagnostics for host-managed types, Dynamic values,
  callbacks, nominal aliases, and external-object contracts.

- 稳定隐式 Optional、裸容器、未绑定 type slot、整体 Dynamic 契约、泛型关系

- 在 native、JavaScript、IR 与 WebAssembly 后端保持并专门化 collection、Ref、
