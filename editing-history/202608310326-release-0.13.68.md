# Release 0.13.68 / 发布 0.13.68

## 中文

- 发布 blocking C FFI callback 的 Unit/EDN 传输修复。
- blocking callback 的 `Unit` 仅在 EDN 传输边界规范化为 `nil`，不改变 Calcit 内部类型与 async terminal 的 `&unit` 协议。
- 真实 `calcit.std/read-file-by-line!` public example 已使用本版本核心验证通过。

## English

- Release the blocking C FFI callback Unit/EDN transport fix.
- Normalize callback `Unit` to `nil` only at the EDN transport boundary without changing Calcit's internal type or the async terminal `&unit` protocol.
- Validate the real `calcit.std/read-file-by-line!` public example with this core version.
