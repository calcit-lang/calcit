# WASM Cirru EDN nominal value 闭环（#1235）

WASI typed Cirru EDN 继续沿用闭合 `DataShapeGraph`，把具名 Enum、core
`Option<T>` / `Result<T,E>` 及其递归 payload 接入现有 parser / formatter；不增加
运行时类型探测、`Dynamic` 中间树或新的命令入口。

Enum 输入使用 `%:: 'TypeName 'variant payload...`。生成的专用 parser 会校验类型名、
variant、payload 数量和每个递归 shape；不匹配时返回稳定的 `E_WASM_EDN_ENUM`。
formatter 复用运行时 enum 布局并生成 canonical Cirru EDN。

验证覆盖 Calcit definition test、真实 Wasmtime nominal roundtrip、Rust 单元/集成测试、
format、clippy、native 与 JS 主套件。完整 `yarn check-all` 另暴露两处与本次改动无关的
既有测试脚本假设：过期的 edit tree path，以及依赖未在主 fixture 中生成的独立
`test-map` / `test-string` JS 文件。
