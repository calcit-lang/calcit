# List `.nth` 到 `.get` 的受证明迁移

List `.nth` 与 `.get` 在前置批次被绑定到同一个 `calcit.core/get` 实现，查询契约均为 `Number -> Option<T>`。这让完整方法调用具备可检查的同实现、同形参和同返回证据；单靠字符串名称不够，特别是 String/Enum 的索引访问与用户自定义方法。

本批复用现有 `CollectionMethodAliasRule`，仅在具体 List receiver、两个方法均 proven、调用来源稳定时将源码 `.nth` 改为 `.get`。开放 receiver 保持 review-only；quoted data、未知 macro 和其他接收者不自动替换。规则只作用于 definition `:code`，不进入已发布 preset，不默默修改 `:tests` 或 `:examples`。

CLI 回归覆盖预览、精确替换、过期 revision 拒绝、应用后 Calcit definition 测试、幂等复查和排除场景。语言语义测试继续由前置批次的 Calcit `:tests` 承担；Rust 测试仅检查 fix 的事务与门禁边界。
