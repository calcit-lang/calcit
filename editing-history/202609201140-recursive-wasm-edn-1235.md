# Recursive WASM Cirru EDN nodes (#1235)

The typed WASM Cirru EDN parser must keep its closed `DataShapeGraph` boundary:
recursive collection parsing is emitted as shape-specialized code, never as an
intermediate `Dynamic` EDN tree. Nested formatter output is parenthesized and
the parser unwraps only that outer expression before handing it to the child
shape parser.

Map keys remain scalar because their native ordering is part of the formatter
contract; map values and Struct fields may now be recursively closed values.
Enum support remains a separate follow-up in the same issue rather than being
represented by a dynamic fallback.

Verification:

```bash
cargo test --lib codegen::emit_wasm::edn --no-fail-fast
target/debug/calcit calcit/test-wasi-command.cirru test app.main/edn-parse-nested-int-lists --require-match
target/debug/calcit wasi calcit/test-wasi-command.cirru --init-fn app.main/edn-nested-roundtrip-main! --emit-path target/wasi-recursive-edn
wasmtime run target/wasi-recursive-edn/program.wasm
```
