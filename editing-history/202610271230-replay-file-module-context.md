# 回放保留文件模块上下文

统一运行器把主 Snapshot 移到临时目录时，原 `./util.cirru` 会从新的目录解析。
原路径上的 79 项 Struct 定义测试全部通过，回放却在执行断言前逐项重复加载失败。
修复留在现有运行器及其宿主协议工具中，不增加公开 CLI 或改变编译器的模块规则。

私有目录按源路径保留所需文件之间的相对位置。入口只取选定 entry 的 modules；
传递模块仍按项目根目录解析，依赖模块本身仍选 default entry，与现有加载器一致。
只复制实际文件模块、其 manifest 和 JS 文件片段，已安装的模块图只读链接复用。
源目录的 cursor、错误状态与写锁不进入回放。缺失模块在准备阶段失败，避免按测试二分
同一个全局加载错误。JS 资源的原 owner 边界保留，越界符号链接不会被复制成合法字节。

验收复用原 Struct `:tests`，加入现有 `check-core-tests`，不改断言或排除表。
临时副本通过 revision 守卫建立 named entry、上级路径和传递模块的真实 CLI 对照，
检查原输入哈希不变及缺失传递文件时明确失败。宿主测试只覆盖私有文件布局、缓存只读、
原状态隔离和资源所有权；不替代 Calcit 语义断言，也不自动授予 FFI feature。
