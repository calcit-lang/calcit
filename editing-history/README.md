# 编辑历史档案

这里保存有助于后续修改的设计决策、复杂故障排查和跨模块契约变更记录。旧方案只说明当时的背景；当前行为以代码、测试、[RFC 索引](../RFCs/README.md)和用户文档为准。

对当前版本已无参考价值的记录可以删除，以减小项目的历史包袱：琐碎记录（机械格式化、版本号发布、简单测试调整、review 跟进），以及描述已删除功能、已移除语法或已退役行为的记录。Git 历史仍保留它们的全文。仍在解释现行设计决策、兼容边界或跨模块契约的记录应保留；被文档、RFC 或代码引用的记录删除前先修正引用。不为统一格式而批量改写已有记录。

今后只有语义设计、复杂故障修复、跨模块契约变化需要新增以年月日时分开头的记录，说明决策依据、兼容边界及验证命令。机械格式化、纯版本号更新和简单测试调整由 commit 与 PR 记录，不强制新增文件。

已有的 [ARCHIVE.md](ARCHIVE.md) 也是历史材料。查找旧记录时可搜索本目录或 Git 历史：

```bash
git log --all -- editing-history/
```
