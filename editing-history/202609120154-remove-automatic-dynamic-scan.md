# 移除普通编译路径的 Dynamic 扫描

## 背景

普通执行此前会遍历 Snapshot、计算 Dynamic 位置占比，并根据比例输出 notice 或 warning。这套启发式统计与预处理类型诊断并行，既增加了启动路径工作，也容易让比例规则代替真正的类型推导与严格诊断。

## 修改

- 移除普通执行和各编译后端共享启动路径中的 Dynamic 使用率扫描与 stderr 提示。
- 删除比例严重级别、提示格式化和对应单元测试，收窄相关 Rust API。
- 暂时保留 `analyze weak-types --format json` 已发布协议需要的内部计数；它只在用户显式运行迁移分析时计算。
- 更新中文文档，明确 warning/error 才是类型判断来源，辅助计数不参与编译门禁，也不应继续扩展比例或分类规则。

## 后续

后续类型收窄优先加强共享类型关系和推导能力；显式迁移分析的进一步合并由独立任务处理，避免在本次修改中破坏 schema v6 消费者。
