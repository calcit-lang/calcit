# Release 0.13.78 / 发布 0.13.78

Issue: #680. Milestone: 0.13.78 — Strict-boundary completion.

This stable release completes the bounded strict-boundary milestone after the
0.13.78-rc.1 consumer validation. It stabilizes strict nil diagnostics and
typed `filter-map-kv` decisions, closes dynamic-dispatch and typed FFI/open-data
evidence, and preserves nominal generic declaration order plus fixed Ref and
Calx buffer invariants.

The release was validated through reviewed provider chains and the named real
application Calcium Workflow, including client/server tests, generated
JavaScript, browser/WebSocket/style lifecycle coverage, and exact post-main
Actions. WASI execution parity is explicitly not claimed: the reproduced
`cr-wasm` preprocess trap remains deferred to #763, with wasi-calcit follow-up
tracked by #753 outside this milestone.

本稳定版在 0.13.78-rc.1 消费端验证完成后，收口严格边界 milestone：稳定 strict
nil diagnostics 与 typed `filter-map-kv` 决策，完成动态派发及 typed FFI/open-data
证据，并保持 nominal 泛型声明顺序、固定 Ref payload 与 Calx buffer 不变量。

发布候选已通过正式 provider 依赖链和 Calcium Workflow 真实应用验证，包括
client/server 测试、生成 JavaScript、浏览器/WebSocket/样式生命周期以及精确
post-main Actions。本版本明确不声明 WASI 执行一致性：已复现的 `cr-wasm`
preprocess trap 延期到 #763，wasi-calcit 后续由 milestone 外的 #753 跟踪。
