# WASI 0.3 command 参数读取

`get-args` 沿用 Calcit 的 `List<String>` 表层接口。在 WASI 0.3 command Component 中，编译器通过 `wasi:cli/environment@0.3.0#get-arguments` 的同步 Canonical ABI 导入取得字符串列表，复用已有 Component List/String lift 转成 Calcit 值；默认 Preview 1 lowering 保持不变。它包含第 0 项命令名，不新增公开命令或适配 API。

以 Calcit definition `:tests` 验证返回值为字符串列表；以真实 Wasmtime 49.0.0 执行参数 `你好` 与 `beta`，通过退出码分别验证 UTF-8 内容和位置。未迁移的 `get-env` 继续在 `--check-only` 中以稳定 capability 诊断拒绝。标准流与其他宿主能力不在本次范围，#1266 仍未完成。
