# 等价类型别名的关系检查

Calcit 0.44.0 中旧值式 Map 别名和 `deftype` 的同形类型引用在双向调用时会被当成不同名义类型；Respo `States` 的渐进迁移因此阻塞 EDN Grid（#2884）。直接展开到每个调用点会复制开放类型，也无法解决通用关系。

仅当两侧都能解析为非名义 schema 别名时比较其展开类型；保留 Struct/Enum/Custom 名义边界、递归保护和不兼容输入的拒绝。迭代快速路径让这类比较交回带保护的别名关系，不改变默认诊断。

评审发现 `Id<Id<Number>>` 被按名称而非完整应用判成循环。别名展开改为识别重复的完整应用并限制展开次数，单侧关系也先展开完整别名链；嵌套泛型正反例与参数持续增长的循环用于验证边界。

验证包含双向正例、开放 Map 进入窄 Map 的负例、原严格 CLI 和库测试、名义类型与别名环回归，以及 Respo 和 EDN Grid 真实依赖候选的全定义检查；真实项目候选尚未发布。性能对照和完整跨后端回归以 PR 的实测记录为准。
