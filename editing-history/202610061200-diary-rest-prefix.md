# Diary 可变参数边界修复

Diary #69 的严格门禁暴露了三个独立边界：core concat 的显式 rest 前缀被错误拒绝、str 的非空列表展开未显式提供必填首参、FFI 取消函数没有独立的 Unit 返回证据。关联 #1529；投影后的类型证据回归也归入 #1553 的后续统一校验范围。

复用 typed_rest_spread_contract，将所有已提供的 rest 实参逐个匹配同一个元素合同，最后的展开操作数匹配 List<rest>。仍拒绝缺少必填参数、多重/非末尾展开及不匹配的元素类型；不改源调用或求值次数，不增加诊断、fix 规则或入口。

str 仅在已有非空分支取首项和剩余列表；FFI cancel 执行原操作后显式返回原本承诺且宿主实现已返回的 Unit，异常传播保持不变。

验证复用现有 CLI 审计测试、fixture 附带 Calcit 测试和全量 native/JS/WASM 回归。记录空/非空展开、显式前缀、错误元素和单次求值；不把三处通过当作 Diary 全部 core 诊断已经清零。
