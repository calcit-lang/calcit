# WASI 0.3 command 退出码

`calcit wasi --boundary component` 的第一阶段只支持正常返回，无法把 Calcit 的 `quit!` 映射到进程状态。这里复用已有的 `0..255` 整数校验，通过 WASI 0.3 command world 的 `wasi:cli/exit@0.3.0#exit-with-code` 导入实现显式退出。默认 Preview 1 路径继续使用 `proc_exit`，公开 Calcit API 不变。

退出调用属于宿主边界，使用 Calcit fixture 加 Wasmtime 真实运行验证状态码；普通纯计算语义继续由 definition `:tests` 覆盖。CI 固定 Wasmtime 49.0.0 CLI 和官方发布资产 SHA-256，保留原有 Rust Wasmtime 依赖用于 Component 结构验证。参数、环境、标准流与文件能力仍分别待实现，不能据此宣称业务闭环已经可用。
