# Value definition to zero-argument function refactor / Value definition 到零参数函数重构

- Add the opt-in `value-to-zero-arg-fn-v1` rule under `calcit fix`, converting one exact value definition, its schema, and compiler-resolved project reads in ordinary code, attached tests, and examples as one staged transaction. / 在 `calcit fix` 下增加显式选择的 `value-to-zero-arg-fn-v1` 规则，将一个精确 value definition、其 schema，以及普通代码、attached tests 和 examples 中由编译器解析确认的项目读取点作为同一个 staged transaction 转换。
- Preserve callee structure by rewriting a function-valued read such as `stored-handler event` to `(stored-handler) event`, and reject quoted data, macro-origin references, dependency source, schema type references, self-referential initialization, or missing source coordinates without writing. / 对函数值读取保留 callee 结构，例如把 `stored-handler event` 改为 `(stored-handler) event`；遇到 quoted data、macro 来源引用、依赖源码、schema 类型引用、自引用初始化或缺少源码坐标时整体拒绝且不写入。
- Validate the staged snapshot strictly, verify that every resolved read is now a zero-argument call, preserve attached test tags, and cover direct reads, callee reads, atomic rejection, idempotence, native execution, and JavaScript codegen with CLI integration tests that execute Calcit-attached behavior and examples. / 严格验证 staged Snapshot，确认每个解析到的读取点都已成为零参数调用，保留 attached test tags，并用会执行 Calcit attached 行为与 examples 的 CLI 集成测试覆盖直接读取、callee 读取、原子拒绝、幂等性、native 执行与 JavaScript codegen。
- Document that this explicit semantic refactor changes evaluation from once at definition initialization to once per call, so it must remain outside migration presets and requires review of side effects, identity, allocation, environment reads, and caching. / 记录该显式语义重构会把 definition 初始化时的一次求值改成每次调用求值，因此必须保持在迁移 preset 之外，并审阅副作用、对象身份、分配、环境读取与缓存语义。
- Address review feedback by rejecting direct references in `defmacro` bodies before resolver usage edits are planned, with staged validation and an atomic no-write regression test. / 根据 review 意见，在规划 resolver usage 改写前拒绝 `defmacro` body 中的直接引用，并补充 staged validation 与原子不写入回归测试。
