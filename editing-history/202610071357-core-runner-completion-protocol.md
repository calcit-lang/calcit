# 跨后端测试运行器的完成协议

统一回放 core `:tests` 时，进程退出码和“每个选中测试已完成”是不同的事实。原运行器仅检查 status=0，测试中的正常提前退出会把后续未执行的测试标为通过。

修复为每个 native/WASI 测试生成开始和结束标记，校验序列与选中测试一致：失败进程允许有效前缀用于定位失败；成功进程必须完整结束全部测试。标记不进入跨后端输出对照，不改变原始测试 AST、断言、schema 或业务预算。

后端参数至少选择一个有效后端，重复后端拒绝执行。排除项发现模式自动加入 native 参照，只有执行成功且输出与 native 一致的项目才建议移除。仍失败的排除项不作为正常测试通过，汇总保持排除数量，最终说明明确指向非排除项。

这些是宿主运行器协议，使用 Node 测试覆盖空参数、重复参数、正常提前退出、乱序/重复/多余标记、失败前缀与错误 parity 推荐；用户语言语义仍由原有 Calcit definition `:tests` 验证。本次不增加或放宽排除项，也不修复排除清单记录的后端语言差异。

与 main 的文档冲突保留新 rem 契约，并把证据入口改为统一运行器；不复活已经替代的脚本。验证继续使用同一批 core 附带测试，实际 native、生成 JS、WASM 与 Wasmtime WASI 回放。已发布 alpha.16 JS runtime 与新 rem 文本断言的差异不能当作运行器错误，源码门禁使用当前源码构建的 runtime，不修改断言或扩大排除清单。
