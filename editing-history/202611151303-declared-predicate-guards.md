# 用 schema 声明谓词守卫

用户可以在函数 schema 中写 `Fn Dynamic (-> Bool) (:guard Number)`。编译器在定义处验证所有返回真的路径，证明函数进入时的第一个参数符合声明。调用方使用已编译的证明，热重载会同时使已变更的守卫及调用方缓存失效。

Core 类别谓词的 `:guard` 同时驱动直接收窄、已有常量折叠和 `data-view` 降级。编译器对内嵌定义核对来源，第三方同名定义需要自己的证明。Nil 与 JS 宿主空值继续走既有专用逻辑。

证明遵循实际控制流。分支绑定只在本分支生效，可能修改入参的真路径无法提供证据。WASM 开放标量可能共享数值表示，与字面量相等无法单独作为跨后端的类型证明。用户可改用 `number?` 等类别谓词。

Calcit 定义测试回放正例和错误类型输入。热重载用例验证恒真、相等比较、真分支证据不完整和局部同名绑定均无法建立声明的证据。
