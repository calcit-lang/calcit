# Release 0.13.78-rc.1 / 发布 0.13.78-rc.1

Issues: #680, #876.

This prerelease breaks the release/consumer validation cycle: it provides an
immutable Calcit artifact containing the nominal generic declaration-order fix
from #878 so Calcium Workflow can validate its canonical
`Result<Value, Error>` schema before the final 0.13.78 release.

Only release metadata changes in this commit. The GitHub prerelease publishes
`@calcit/procs` under npm dist-tag `next`; stable npm `latest` remains unchanged.
The final release remains blocked until Calcium passes against this exact
prerelease and all remaining milestone acceptance is complete. As already
decided for this milestone, WASI execution parity is not claimed by 0.13.78.

本预发布用于打破发布与消费端验证之间的循环：提供包含 #878 泛型声明顺序修复的
不可变 Calcit 产物，让 Calcium Workflow 在正式 0.13.78 前验证规范的
`Result<Value, Error>` schema。本提交仅包含版本、lockfile 与发布说明元数据；
npm 预发布只更新 `next`，不会移动稳定通道 `latest`。Calcium 精确预发布验证和
其余 milestone 验收完成前，不发布正式版；本版本也不声明 WASI 执行一致性。
