# 发布 0.13.69 / Release 0.13.69

## 中文

- 发布版本化 typed FFI Interface IR v1 与只读 `calcit ffi export` inventory。
- 包含确定性 canonical schema/lowering revision、结构化 unsupported diagnostics、JSON Schema、文档与 agent stdout 守门。
- 为后续 regex、async stream/cancel 和 opaque resource 三类 bindgen 试点提供可安装 CLI 基线。

## English

- Release the versioned typed FFI Interface IR v1 and read-only `calcit ffi export` inventory.
- Include canonical schema/lowering revisions, structured unsupported diagnostics, the JSON Schema, documentation, and the agent stdout gate.
- Provide an installable CLI baseline for the upcoming regex, async stream/cancel, and opaque-resource bindgen pilots.
