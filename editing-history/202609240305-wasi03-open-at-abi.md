# WASI 0.3 异步 open-at 的真实 host 契约

在 `#1267` 的文件效果接入前，先验证 `descriptor.open-at` 的 Canonical ABI，避免把异步调用误当同步函数。测试从 host 的具名 preopen 选择目录，使用间接参数记录传入借用的 descriptor、路径 flag、相对字符串、open flag 与 descriptor flag；根据调用状态等待 subtask 完成，再归还 waitable set、subtask、preopen 及成功打开的文件 descriptor。

真实 Wasmtime 49 WASI 0.3 host 对存在的文件成功打开，对不存在的文件返回失败状态，两个路径均无 host trap。运行时需显式启用 Wasmtime 的 `component-model-async-stackful` 特性；否则 Component 尚未执行就会在解析阶段被拒绝。此测试加入 CI，后续正式 lowering 应复用已验证的布局和生命周期，并补全错误分支与 stream 读写。

本次只建立低层 ABI 契约，不放开 Calcit 的 `&fs-read-text` / `&fs-write-text`；完成可用文件效果仍需真实 Manifest 业务回归。
