# 升级 calx_vm 0.6.0 并编译严格 Tag

## 背景

calx-vm 0.6.0 已发布，修正了历史上的 `:tag -> Str` 别名：`|text` 是 `Calx::Str`，`:name` 是独立的 `Calx::Tag`。Calcit 之前只在 Calx 路径支持 Str，Tag 被排除在 program profile 之外。本改动固定正式版本并把 Tag 纳入 strict scalar lowering。

## 修改

- `calx_vm` 依赖从 `=0.5.1` 升级到 `=0.6.0`（`Cargo.lock` 仅更新该 crate 版本与 checksum）。
- `CalxScalarType` 增加 `Tag`（追加在已有 variants 之后，避免历史 discriminant/排序变化），映射 `CalxType::Tag`；新增 `CalxEligibilityProfile::allows_tag`，与 String 一样只在 Program profile 生效。
- eligibility 与 lowering 支持 Tag 字面量、`Tag` 类型注解的 local、参数、返回值；`CalxValue::Tag` 与 `Calcit::Tag` 边界双向转换，Str/Tag 不匹配仍在边界拒绝。
- `coverage.rs` 将 `Tag` 从 planned `PROGRAM` 调整为 `CalxCore` 的 ProgramFoundation；`Symbol` 继续留在 planned。
- 新增 `tests/fixtures/calx/tag-values.cirru` 与 Rust 后端测试，覆盖 Tag 跨 lifecycle call/local/host import 的执行，以及 String 传入 Tag 契约时的边界拒绝；原 Tag/Symbol 拒绝测试收窄为只验证 Symbol。
- 按 #989 的 Calcit-first 规则，为 `calcit.core/&compare` 增加 definition `:tests`，以用户可观察表达式断言 Tag 与 String 的区别（`:a`/`|a` 排序与相等）。
- 重新生成 `docs/core-dynamic-classification.md`（core revision 变化）。

- `node scripts/check-strict-default.mjs`、`node scripts/core-dynamic-classification.mjs --check`
- `analyze quality --baseline config/calcit-core-quality.cirru`（baseline 不变）
- `bash scripts/check-docs-md.sh`、`yarn try-js`、`yarn try-wasm`
- wasm32 lib check 本地未安装 target，交由 CI 验证。
