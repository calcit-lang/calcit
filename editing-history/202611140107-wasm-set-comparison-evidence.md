# WASM 差集与交集的元素类型证据

差集和交集的结果只取自左侧，因此两侧集合可以拥有独立的元素类型。WASM/WASI 结构比较使用未带类型标记的数值表示。不同种类的值可能有相同表示，包括 Tag 与 Number，以及结构成员中的 Bool 与 Number。

后端在两个操作共享的比较入口检查对应位置的类型证据。Tuple 按位置比较，List/Set 检查元素，Map 分别检查键和值，名义 Struct/Enum 使用实际字段或 payload 合同。开放、无法解析或超出递归检查范围的形状报告现有的 `E_WASM_SET_ELEMENT_KIND`。空集合没有可比较的元素。公开变参入口沿用左侧集合及各额外实参的证据。

原有 native/JS 结构相等规则继续决定结果。Calcit 定义测试回放同型嵌套 List 和 Tag，CLI 回归验证 WASM/WASI 拒绝有碰撞风险的输入且不生成文件。其他比较入口的通用运行时表示见 #2762。
