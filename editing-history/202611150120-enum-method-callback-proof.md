# 枚举方法的回调证明

在 #2735 将 `turn-tag` 的 Rust 签名改为读取 core 后，应能继续把它作为 `Result<Number, String>` 错误分支的映射函数。旧枚举实现分支直接比较函数注解，未按方法的接收者证据实例化回调自己的泛型，导致原有的 `.map-err turn-tag` 报错。

枚举方法先沿用原有参数匹配。遇到一等泛型回调且原匹配失败时，用接收者已绑定的合同调用现有泛型证明。这样保留兄弟回调共享的返回类型绑定。使用不同命名空间的同名 Struct 作为两条回调的结果仍在 lowering 前报方法参数错误。现有测试覆盖两种 Result 分支，默认严格检查同时验证返回类型与拒绝错误回调。
