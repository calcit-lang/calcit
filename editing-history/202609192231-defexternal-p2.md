# defexternal 简写 P2：calcit edit 写入路径（#1223）

- `normalize_schema_for_code` 增加识别 `defexternal`，写盘时把 schema 归一化为 `:: 'Trait`
  （此前 `calcit edit def` 写出的 defexternal entry 会是 `:: 'Dynamic`）。
- 新增 `snapshot::validate_defexternal_shorthand`，`calcit edit def` 写盘前校验简写：
  非法 `:target` 等错误在编辑边界即失败，不会写入无效 Snapshot 再留到下次载入。
- 实测端到端：`calcit edit def <ns>/QueryHost --input-format cirru --file <defexternal snippet>`
  成功写出 `defexternal` 代码 + `:schema :: 'Trait`；非法 `:target :deno` 被拒绝且未写入。
- RFC 状态与 `RFCs/README.md` 更新为 P1/P2 已落地；`docs/features/js-interop.md` 3.3 补充
  `calcit edit def` 用法与写盘行为。
- 测试：`src/snapshot.rs` 新增 `defexternal_canonicalizes_write_schema_to_trait_marker` 与
  `validate_defexternal_shorthand_accepts_valid_and_rejects_invalid`。
- 验证：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test` 全绿；
  docs check-md 69/69；`calcit/test.cirru --compat-types` 与 `check-strict-default.mjs` 通过。
- 剩余：P3（是否保留 `defexternal` 源码头而非载入/写盘归一化）留待评估；载入期仍会把
  `defexternal` 展开为 `deftrait` + `:ffi`。
