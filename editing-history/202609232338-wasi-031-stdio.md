# WASI 0.3.1 标准输出切片 / WASI 0.3.1 output-stream slice

2026-09-23 23:38 +0800

## 中文

为 #1266 实现 `println`、`eprintln`、`echo` 到 WASI 0.3.1 stdout/stderr 的编译器内部 lowering，不增加 Calcit 表层 API 或命令入口。WASI `write-via-stream` 使用 stream/future handle，处理部分写入并释放 handle；有输出的命令使用 async stackful run，未用输出的命令保留现有轻量入口。Calcit fixture 验证中文、参数间空格、换行和 stdout/stderr 分离；bindgen 的独立 ABI 测试验证 1 MiB 部分写入。Wasmtime 49 仍需显式启用两个 Component async 特性。stdin 和输出完成 future 的错误传播尚未覆盖，不关闭 #1266。

## English

For #1266, lower `println`, `eprintln`, and `echo` internally to WASI 0.3.1 stdout/stderr without adding a Calcit surface API or command. `write-via-stream` uses stream/future handles, loops over partial writes, and drops ownership; commands that print use an async stackful run export while commands without output retain the lighter entry. A Calcit fixture checks Chinese UTF-8, argument spacing, newlines, and stdout/stderr separation; an independent bindgen ABI test exercises a 1 MiB partial write. Wasmtime 49 still needs two explicit Component async feature switches. Stdin and completion-future error propagation remain open under #1266.
