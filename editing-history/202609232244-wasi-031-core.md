# WASI 0.3.1 command migration / WASI 0.3.1 命令迁移

2026-09-23 22:44 +0800

## 中文

- Calcit #1295 先升级现有显式 `calcit wasi --boundary component`，不提前切换默认 Preview 1，也不增加公开 CLI 入口或表层类型。正式 `calcit-bindgen 0.1.9` 固定 WASI v0.3.1 WIT；Calcit core 同步 `wasi:cli` 的 run、environment、exit 名称。
- 将生产与测试依赖都固定为 crates.io `calcit-bindgen =0.1.9`，移除本地 path 探针。`Cargo.lock` 仅改变该包的版本和 checksum。
- 官方 Wasmtime v49.0.0 macOS arm64 资产 SHA-256 为 `7be00c6d3f3a4a5457820dccfeffec4fa47db124f00dc1b77f7e7477b78ac066`。本机不覆盖旧版安装，而在隔离临时目录运行此二进制；发布版 bindgen 依赖下 `wasi_command_component_cli` 7/7 通过，包括参数、环境、退出码及拒绝路径。bindgen 的正式 CI 也用 Wasmtime 49.0.0 运行 v0.3.1 Component。
- Wasmtime 49 内置 p3 CLI WIT 文字仍为 0.3.0，真实运行证明这里使用的 0.3.1 command 子集兼容；不据此宣称尚未迁移的标准流、文件系统、时钟或随机数已经支持。后续由 #1266/#1267 实现，#1268 验收，#1269 再切默认。

## English

- Calcit #1295 upgrades only the existing explicit `calcit wasi --boundary component` path. It does not switch the Preview 1 default, add a CLI entry, or expand surface types. Released `calcit-bindgen 0.1.9` pins official WASI v0.3.1 WIT, and Calcit core aligns the `wasi:cli` run, environment, and exit names.
- Both production and test dependencies use the exact crates.io `calcit-bindgen =0.1.9`, removing the local path probe. `Cargo.lock` changes only that package version and checksum.
- The official Wasmtime v49.0.0 macOS arm64 asset has SHA-256 `7be00c6d3f3a4a5457820dccfeffec4fa47db124f00dc1b77f7e7477b78ac066`. A verified binary in an isolated temporary directory passed all seven `wasi_command_component_cli` tests against the published bindgen dependency, including arguments, environment, exit status, and rejection paths. Bindgen CI also executes v0.3.1 Components under Wasmtime 49.0.0.
- Although Wasmtime 49 labels its bundled p3 CLI WIT 0.3.0, real execution establishes compatibility for this v0.3.1 command subset. It does not imply support for unported streams, filesystem, clocks, or random. Issues #1266/#1267 add those capabilities, #1268 validates the application loop, and #1269 switches the default later.
