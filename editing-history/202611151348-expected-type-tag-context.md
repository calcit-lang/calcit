# 统一裸标签的期望类型检查

集合成员、结构体字段、枚举负载、函数与方法参数和 `recur` 参数都将声明的类型交给同一个期望类型入口。裸标签在这个入口解析为枚举分支，诊断仍指出原参数或字段。分支、`let` 末项、展开后的宏和集合成员沿各自的语义位置传递期望类型。

函数以其他实参、已确定的返回语境或接收者合同建立参数类型。方法检查不把当前正在被解释的裸标签当成自己的类型证据。已绑定的普通 Tag 保留其类型。结构体的字段形状、Option 提升和运行时 spread 校验沿用各自合同。

验收包括原有 CLI 的通过与诊断用例、普通 Native 和生成 JS 执行，以及具名结构体的合法枚举字段与拼错标签。
