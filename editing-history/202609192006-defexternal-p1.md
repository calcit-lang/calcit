# defexternal 简写 P1：载入期规范化（#1223）

- `src/snapshot.rs` 新增 `defexternal` 简写解析与展开：
  - `normalize_defexternal_code`：解析 `:target`/`:names`/`:writable` 选项与 `:field`/`.method` 成员，
    生成 `deftrait` 代码 + `:ffi` 元数据（`:backend :js`、`:kind :external-object` 固定）。
  - `normalize_entry_external`：在文本与二进制两条载入路径（`TryFrom<Edn> for CodeEntry`、
    `RawCodeEntry::into_code_entry`）统一应用；显式 `:ffi` 与 `defexternal` 同时存在时报错。
  - 规范化发生在 `normalize_schema_for_code` 之前，因此 `deftrait` 仍被识别为 trait schema。
- 稳定错误覆盖：未知/重复 `:target`、显式 `:backend`/`:kind`、缺少成员、非法 `:names`/`:writable` 形状、
  与显式 `:ffi` 冲突。
- 保持分层语义：preprocess/type/codegen/query 零改动；`calcit query def --json` 的归一化 `ffi` 输出不变。
- 测试：`src/snapshot.rs` 新增 5 个单测（展开与元数据、省略空选项、非法 target/backend、缺成员/重复 target、
  与显式 ffi 冲突）；本地 `--check-only` 与 `query def` 端到端验证展开结果。
- 文档：`docs/features/js-interop.md` 3.3 增加 `defexternal` before/after 示例；RFC 状态更新为 Partial。
- 验证：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test` 全绿；
  docs check-md 69/69；`calcit/test.cirru --compat-types` 与 core 单测 304 通过。
